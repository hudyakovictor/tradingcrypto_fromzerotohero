## 0. Что это за проект (30 секунд)

**Signal Arena** — мобильная PWA-игра: тренажёр **качества торговых решений** на исторических рыночных ситуациях крипторынка.
Игрок смотрит «браузер трейдера» (график, вкладки-источники, карты навыков), принимает одно из 4 решений — и только потом видит заранее зафиксированное продолжение истории. Награда — за **качество мышления (0–100)**, а не за угаданное направление свечи. Это НЕ терминал, НЕ демо-счёт, НЕ play-to-earn.

Стек (фиксирован, не менять): **Phaser ^4 (WebGL) + TypeScript + Vite · rexUI · кастомный CandleChart на Graphics · Zustand (vanilla, без React) · seedrandom + свой scenario-gen · Fastify + SQLite + Drizzle + Zod + WS · Phaser Sound · vite-plugin-pwa · Vitest + Playwright · pnpm workspaces**.

## 4. Десять заповедей агента

1. **DONE без зелёных тестов — ложь.** Гейт: `pnpm -w typecheck && pnpm -w lint && pnpm -w test` (+ `pnpm e2e`, если тронут клиент). Команды появятся после T-P0-02…06; до этого гейт — что есть, фиксируй в логе.
2. **Один агент — одна задача за сессию** (атом ~1 сессия). Не помещается — дели задачу или завершай как `PARTIAL` с точкой продолжения.
3. **HANDOFF_LOG — append-only.** Никогда не редактируй и не удаляй чужие записи.
4. **Не трогай чужой `IN_PROGRESS`**, пока протокол сирот (AGENT_PROTOCOL §3.3) не разрешит.
5. **Контракты (`packages/shared`) не меняются молча** — только с ADR и бампом версии контракта.
6. **Продуктовые запреты абсолютны** (docs/spec/00_OVERVIEW.md §3): нет P2W, нет выводимой валюты, нет обещаний прибыли, награда только за качество процесса, рынок не подгоняется под ответ, будущее задания скрыто до фиксации решения.
7. **Каждая новая фича отвечает на 8 контрольных вопросов** (00_OVERVIEW.md §4). Нет ответа — фича не пишется.
8. **Тон текстов — панк-таблоидная криптосатира** (style-tone.txt). Тексты вне тона = брак.
9. **Детерминизм свят**: один seed → один и тот же сценарий, байт в байт. Хочешь `Math.random()` — остановись и перечитай 01_ARCHITECTURE.md §8.
10. **Закончил сессию — оставь след.** Код без обновлённого STATUS/TASK_BOARD/HANDOFF считается несделанным, следующий агент вправе его переписать.

## 5. Если ты — первый агент после бутстрапа

Система документации уже развёрнута (задача `T-P0-01` = DONE). Твоя первая задача — смотри `STATUS.md` → «Ближайшие задачи». На момент бутстрапа это `T-P0-02` (скаффолд монорепо).

Быстрый старт-копипаст для запуска тебя самого — в `docs/prompts/BOOTSTRAP_AGENT.md`.
