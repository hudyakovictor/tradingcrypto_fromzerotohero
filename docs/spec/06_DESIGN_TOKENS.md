# SPEC 06 — DESIGN TOKENS & ART DIRECTION

Все значения оформляются файлом `packages/content/design-tokens.json` (T-P3-01) и подгружаются темой. Литеральные цвета в коде — брак. Названия токенов ниже — обязательная номенклатура.

## 1. Палитра (по концептам c1/c3: глубокий тёмный фон + неон)

```jsonc
{
  "color": {
    "bg":      { "0": "#05070F", "1": "#0A0E1A", "2": "#0F1424" },   // фон, панель, приподнятая
    "glass":   { "fill": "rgba(19,26,48,0.72)", "stroke": "rgba(94,240,255,0.25)" },
    "text":    { "hi": "#F2F6FF", "mid": "#AAB6D3", "low": "#5D6B8C" },
    "neon":    { "cyan": "#3EF2FF", "teal": "#1FD8C4", "purple": "#8A5CFF",
                 "magenta": "#FF3EA5", "pink": "#FF7AE0" },
    "signal":  { "good": "#41F0A0", "warn": "#FFC24B", "bad": "#FF4D5E" },
    "candle":  { "up": "#25E0A4", "down": "#FF4D6D", "wickUp": "#7FF2CE", "wickDown": "#FF9BAD" },
    "gold":    { "main": "#FFC24B", "deep": "#B98A2E" },   // награды, пасс, эмблема

```

## 2. Типографика (кириллица обязательна)

- Display/заголовки: **Russo One** (или аналог OCR-condensed с кириллицей) — uppercase для панк-заголовков.
- UI/body: **Manrope** (или Inter) — кириллица, tabular-nums для чисел.
- Моно (адресная строка, хэши, цены): **JetBrains Mono / IBM Plex Mono**.
- Шкала: 12 / 13 / 15 / 18 / 24 / 32 / 44. Веса 400/600/800.
- Шрифты самохостятся в `public/fonts` (woff2, subset ru+en); системный фолбэк прописан.

## 3. Компонентные токены

```jsonc
{
  "radius": { "s": 8, "m": 14, "l": 22, "pill": 999 },
  "border": { "glassM": "1px rgba(94,240,255,0.25)", "neonM": "2px #3EF2FF" },
  "glow":   { "cyan": "0 0 12px rgba(62,242,255,0.55)", "red": "0 0 12px rgba(255,77,94,0.55)" },
  "spacing": [4, 8, 12, 16, 24, 32, 48],
  "z":      { "base": 0, "sticky": 10, "overlay": 50, "toast": 90, "debug": 99 }
}
```

В Phaser glow эмулируется запечёнными текстурами/двойным контуром с альфой (токены `glow.*` хранят CSS-нотацию для справки и HTML-оверлеев).

## 4. Ключевые компоненты (поведение слоёв)

- **Glass-panel**: bg.1 + glass.fill, border glassM, blur-decor допускается фейковым (градиентная подложка).
- **Neon-button (решения)**: bg.2, 2px контур цвета квадранта (A cyan/B purple/C amber/D red), внутренняя плашка буквы; press = scale 0.97 + усиление glow на 150 мс.
- **Skill-card**: 96×128 минимум, рамка `border.glassM`, центр — объект-иконка на прозрачном; selected → контур cyan + glow; recommended → пульс gold; locked → grayscale + замок.
- **Tag/чип**: pill, bg.2, текст 12 mid.
- **Progress/Threat bar**: трек bg.2, заливка градиентом signal или entity-категории.
- **Stamp-печати** («НЕ ФИНРЕКОМЕНДАЦИЯ», вердикты): наклон −6°, контур 3px, magenta/red, текст uppercase mono.

## 5. Иконки

- Стиль: контурные, сетка 24, stroke 2, скругления 2, один акцент-цвет.
- Стартовый набор: tab-иконки (свечи, бары, %, газета, куб, кит, календарь, чат, история, журнал), topbar (помощь, колокол, шестерня, монета, $SIG), nav (шапка-академия, кот/зверёк-бестиарий?, скрещённые мечи-арена, витрина-маркет, кубок-турниры), сервисные (замок, звезда, плюс, стрелки, дисклеймер).
- Формат: SVG-мастера в `assets-src/icons/` → в игру через спрайт-атлас или заливку Graphics. Цвет через токен, не через SVG-fill хардкод.

## 6. Логотип и бренд (по brand readme)

- Знак: S + инь-янь (бык снизу, медведь сверху) в круге — см. `template_low-details.png`; официальная художественная версия — золотая барочная эмблема (`template_high-details.jpeg`).
- Уровни детализации: compact (эмблема-линия, favicon/tab), main (сайт, topbar art), app-icon (детализированные головы, объём, свечи), illustrative (заставки/реклама — свободная работа).
- Не путать символику: бык/медведь = рыночные силы, НЕ персонажи-файтеры. Айдентика = «арена сил», Mortal-Kombat-пульс в драматичности, не в насилии.

## 7. Три слоя визуала (жёсткое правило смешения)

1. **Игровой UI** — неон-стекло c1/c3 (основной язык интерфейса).
2. **Иллюстрации сущностей/карт** — тёмный комикс top1/top2.
3. **Настроение/фоны/печати** — панк-коллаж top3 (газетные обрывки, граффити, стикеры): только декоративно, интенсивность ≤ 30%, никогда под текстом-данными без подложки; в MissionScene работает тихо (граффити угасает на фоне анализа — концепт-2 «краски −30%»).

На экране не смешиваются пиксельно: иллюстрация сущности живёт в раскрытии/бестиарии, UI-неон — в аналитике, панк — в типографике и печатях.

## 8. Аудио-направление (Phaser Sound)

- Набор: ambient-луп (тихий электрический гул арены), UI тики/whoosh, commit-heavy (удар печати), reveal-tick (на свечу), verdict sting (3 варианта: optimal/acceptable/poor), entity-reveal riser. Все файлы ≤ 150 КБ (ogg+mp3 fallback), лоудер-группа `sfx`.
- Громкость по шинам master/music/sfx, настройки в `settings`. Reduce-motion отключает riser-визуал, не звук.
