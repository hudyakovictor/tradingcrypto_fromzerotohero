# SPEC 03 — UX/UI: все экраны 0 → 100%

Референсы (master: ideas-ui.zip): **концепт-1** = минимальная база; **концепт-2** = эталон тона текста + Маркет/Debrief («краски −30%»); **концепт-3** = карта разделов (Hub/Battle/Bestiary/Cards/Shop/Leaderboard/Quests). Пиксель-эталон — минимальный набор (`minimal-set-...png`). Дизайн-токены — SPEC 06. Тон текстов — style-tone.txt (RU-мастер).

## 1. Глобальные правила

- Design space **420×900 portrait**, safe-area сверху/снизу ≥ 16pt; всё важное доступно большим пальцем: зона тапов нижние 65% экрана.
- Тап-таргет ≥ 44×44. Шрифт UI ≥ 13px (в дизайн-координатах). Контраст текста ≥ 4.5.
- Миссия целиком укладывается в 90 секунд медианно; чтение ситуации ≤ 15 секунд.
- Один экран = одна мысль. Запрещены: формы с 3+ полями в бою, настоящие поля ордеров (цена/объём/плечо/стоп/тейк одновременно), скролл внутри скролла.
- Навигация снизу (финал, 5 пунктов): **Академия · Бестиарий · Арена · Маркет · Турниры**. В MVP (P4): **Академия · Арена · Журнал · Ещё** (Бестиарий и Профиль под «Ещё»); перестройка в 5 пунктов — задача P6/P7 без ломки жестов.
- Все строки через i18n-ключи (RU master). Жёстко забитых строк нет.
- Reduce-motion: все твины/партиклы имеют «тихий» вариант. Звук по умолчанию ON, есть глобальный мьют в TopBar/Settings.
- Ошибки сети — тост + состояние экрана «офлайн-режим», игра продолжает работать на контент-паке.

## 2. Boot / Preload

- Boot: чёрный экран → эмблема S-иньянь (low-detail версия), проверка WebGL, инициализация stores/i18n.
- Preload: прогресс-бар «неоновая линия с глитчем», подписи-ротация в тоне («БУФЕР ОБЕЩАНИЙ ЗАГРУЖЕН. Прочность не гарантирована.»). Показывает версию контента и клиента.
- Fail-стейты: нет WebGL → понятный экран-заглушка; повреждённый контент-пак → авто-рефетч.

## 3. Onboarding (обязателен, короткий, пропускаемые объяснения)

Цель — обучить ИНТЕРФЕЙСУ, не теории трейдинга. Прогрессивное раскрытие (конституция §11), 10 шагов, каждый — подсвеченный элемент + 1 фраза + «Далее/Пропустить всё»:

1. Экран задания целиком («Вот арена. Враг тут — твоя спешка.»)
2. Текст ситуации
3. Вкладка графика
4. Вторая вкладка-источник
5. Первая карта навыка (применить к делу)
6. 4 варианта решения
7. Разбор (демо-задание с мгновенным раскрытием)
8. Дополнительный шаг (размер риска)
9. Сущности («Это не монстр. Это ты в четверг.»)
10. Протоколы + остальные вкладки

Правила: опытный игрок проходит за ≤ 90 с (skip объяснений), новичок ≤ 4 мин; после onboarding базовый интерфейс ОТКРЫТ ПОЛНОСТЬЮ — дальше растёт только сложность контента, не каркас. E2E-тест `onboarding.spec` обязателен.

## 4. Арена — MissionScene (ядро; экран задания)

Анатомия сверху вниз (соответствие минимальному набору):

### 4.1 TopBar (высота 56)
`[?] помощь` · `XP бар уровня` · `монеты` · `$SIG` · `колокол` · `⚙`. В миссии top bar усечён: прогресс + звук + выход (с подтверждением «Уйти = сдаться. Рынок тебя запомнит. Нет. Но запомнит.»).

### 4.2 Текст ситуации (≤ 2 строки + развёртывание)
Комикс-бабл/плашка. Стиль: «Пробой без объёма. Объём молчит.». Тап — лонгрид контекста (модалка, ≤ 5 строк).

### 4.3 BrowserWidget (≈ 45% высоты) — «браузер трейдера»
- Хром: 3 цветные точки слева, **адресная строка** `arena://{symbolShown} · {tf}` с иконкой ⟳ (твист: обновление ничего не делает, фраза-подкол раз в N тапов).
- **Панель вкладок-иконок** (1–7): chart свечи / бары объёма / % макро / газета / куб on-chain / кит / календарь / чат / история позиции / журнал-сердце. Иконки без подписей после онбординга (заучивание) — референс концепт-1. Активная вкладка — неоновая подсветка; неоткрытая новая — микро-пульс.
- Контент вкладки: полупрозрачная тёмная панель; рендеры:
  - `chart` → CandleChart (SPEC 01 §5) + level-линии + маркер DECISION POINT у правого края;
  - `volumeLiquidity` → стакан-полосы («КИТОВАЯ СТЕНА» бейдж), funding/OI тайлы;
  - `news` → карточки-заголовки таблоида (обфусцированные, тон style-tone);
  - `sentiment` → шкала страх/жадность, соц-шум бары;
  - `onchain` → flows in/out бар, unlock-календарь;
  - `position` → карточка открытой позиции (для inPosition-миссий);
  - … остальные по SPEC 02 §2.
- Запрет: вкладка без влияния на решение не показывается вовсе (нет декоративных).

### 4.4 CardTray (ряд карт навыков, 4–5 видимых)
Карта: рамка, центральный объект-иконка (средняя детализация!), краткое имя, звёзды мастерства (0–3); состояния:
- `available` (нейтраль), `selected` (неоновый контур + лёгкий подъём), `recommended` (тёплое свечение — только низкие уровни; тренирует 20/80: «правильно заметить, что полезно, и не тратить время»), `locked` (серые, замок, тап → тост «Откроется: глава N»);
- тап по карте = применить принцип к ситуации (фиксируется в попытке; само по себе очков не даёт — даёт при согласованности с решением и данными, LOGIC §2);
- лонг-тап/иконка ⓘ → боттмшит карты: принцип (1 строка), развёрнутое объяснение (≤ 3 строк), ссылка в Академию.
- Максимум буквы: название ≤ 14 символов RU.

### 4.5 DecisionBar — 4 кнопки A/B/C/D (всегда 4, всегда на месте)
- Сетка 2×2 (мобильный эталон) или 1×4 (узкие короткие подписи). Каждая: бейдж буквы с цветом квадранта (A cyan / B purple / C amber / D red) + подпись ≤ 5 слов.
- Состояния: idle / pressed (масштаб 0.97 + вспышка) / disabled (нет) / `committing` (после тапа: блокируем все 4, шлём на сервер).
- Подтверждение не требуется (одно решение — один тап; обучение точности), но есть 400 мс «отмена» если ещё не отправлено? — **НЕТ**: решение фиксируется тапом (принцип «решения имеют вес»). В heuristics лог.

### 4.6 ExtraStepDock (нижняя выезжающая панель; только если сценарий требует)
Модификации по `ExtraStep.kind`:
- `riskSize`: слайдер % риска (0.5–5), крупные тики, текущее значение плашкой;
- `invalidation`/`confirmation`/`pauseChoice`: чипы-варианты (≤ 4);
- `evidencePick`: режим «отметить до maxPicks элементов доказательств» — подсвечиваются кликабельные артефакты во вкладках.
Панель скрыта, пока не выбрано основное решение (поток: решение → dock → «Подтвердить» → commit).

### 4.7 Присутствие сущности
НЕ «полоса HP босса». Индикатор ДАВЛЕНИЯ: мини-портрет/силуэт + датчик «FOMO/ШУМ/…» (из entity). Правила по уровням (конституция §7): низкие — имя и портрет видны («Fake Breakout Phantom»), средние — безымянный силуэт, высокие — ничего до разбора. Таймер допустим только скрытый; скорость никогда не главный критерий.

## 5. RevealScene + DebriefScene

**Reveal**: камера в чарт; маркер «РЕШЕНИЕ ПРИНЯТО» фиксируется на t0; fog отползает, свечи дорисовываются (tick-sfx), fore-события помечаются. Кнопка «пропустить». Сущность «разоблачается» тут, если tier позволяет (граффити-печать «ТЫ РАЗОБЛАЧИЛ ФАНТОМА» / «ФАНТОМ УШЁЛ КОРМИТЬСЯ К МЕНЕЕ ВНИМАТЕЛЬНЫМ», stamp «НЕ ФИНРЕКОМЕНДАЦИЯ»).

**Debrief** — строго 3 слоя, в одном скролле:
1. **Рыночный факт**: мини-чарт итога + «как было на самом деле» (дата/инструмент/источник, если допустимо).
2. **Последствие действия**: сравнение «что было бы» (по зафиксированной модели), бары P&L-guess vs outcome. Подпись дисклеймера.
3. **Качество решения**: кольцо 0–100 + 5 полос критериев (контекст/доказательства/действие/риск/дисциплина) + текст разбора «факт → логика → переносимое правило» + награды (+XP/+монеты/+$SIG чипы) + «правило записано в журнал».
CTA: «Следующая охота» / «В журнал». Неверные → кнопка «Разобрать ошибку (Академия)».

## 6. AcademyScene

Главы → уроки (карточки ≤ 90 c чтения). У каждой главы: обложка, прогресс, «открывает карты/сценарии» бейджи. Урок: заголовок-панк + 3–6 коротких блоков + 1 мини-пример с графиком (статичный CandleChart frame). Финал главы: «глава закрыта» → награда монетами + разблокировка сущности в бестиарии («теперь ты видишь её насквозь»). Связки двусторонние: урок → рекомендованные сценарии; ошибка в миссии → нужный урок.

## 7. BestiaryScene

Список сущностей: иконка, имя, категория-чип, Threat x/99 прогресс, encounters, win-rate, ✔ DEFEATED. Фильтры: категории (Рынок/Эмоции/Шум/Риск/Web3) + типы (Phantom/Wraith/Titan/Hydra/Cult/Mimic/Siren/Goblin/Mirage/Syndicate/Dragon/Parasite/Leviathan/Golem/Sphinx/Slime/Spider/Imp/Poltergeist/Leech/Chimera — из GAME_LOGIC §8). Деталь: арт (top1-стиль), описание проявления, «Слабость», «Контр-карты» (минимайки карт), «Связанные ошибки», мини-схема паттерна, CTA «Вызвать на арене» (подбирает сценарий с этой сущностью). Скрытые/неоткрытые — силуэт + «Rank N+».

## 8. JournalScene

Не «свиток ошибок», а персональная история: горит «огонёк ошибок». Секции: **Повторяющиеся паттерны** (карточка: название искажения, счётчик, «закрыть» через целевые сценарии), **Сильные навыки**, **Слабые зоны**, **История решений** (строки: дата-псевдо, сценарий-алиас, скор, вердикт-цвет), **Стрик** «дней с закрытой ошибкой». Из любой карточки — переход в Академию/Арену.

## 9. TournamentScene (P7)

Список турниров (название, окно, число заданий, награды-косметика, квота попыток). Экран серии: те же MissionScene, фиксированный seed-набор, reveal только после закрытия окна/своей попытки. Leaderboard: качество → соблюдение протокола → доказательства/доп. шаг → скорость (tie-break). Никаких «призовых денег» — косметика/титулы.

## 10. HubScene

Крупный баннер «ENTER BATTLE» (арт-сцена + следующая цель), дейли-виджет («3 цели»), мини-профиль (уровень, стрик), мини-лента «последние бои». Тапы ведут в разделы. Фон — панк-коллаж низкой интенсивности (SPEC 06 §7, ≤ 30% визуального шума).

## 11. MarketScene (P8)

Вкладки: Магазин / Пасс / Подписка / Паки (как концепт-2). Правила UI-честности: каждая карточка товара содержит микро-дислеймер «не влияет на бой»; запрещённые категории не рендерятся вообще (тест P8 гарантирует: ни один SKU не меняет scoring/данные/лимиты). Покупка → инвентарь (косметика: темы чарта, рамки карт, аватары, звук-паки, фоны победы). Цены в ₽/$ — только реальные деньги за косметику/контент-паки; игровые ресурсы за них не продаются.

## 12. Settings / Profile

Профиль: хэндл, уровень 0–99 с «таблицей устойчивости» (матрица условий), аватар-косметика. Настройки: звук (мастер/музыка/sfx), reduce-motion, локаль (RU, EN; архитектура 10+), «удалить данные», правовые страницы («Не финансовый совет», приватность). Кнопка «Повторить onboarding».

## 13. Системные состояния (каждый экран обязан реализовать)

- `loading` (скелеты/шиммер-токены), `empty` (панк-фраза + CTA), `error` (тост + retry), `offline` (значок, доступные разделы работают), `first-visit` хинт (1 раз, записывается в профиль), `reduce-motion` ветка анимаций.

## 14. Жесты и ввод

Тап — основной. Лонг-тап — детали карты/вкладки. Свайп вниз на модалках — закрыть. Никаких свайпов «в сторону» на решениях (риск случайного). Тактильный отклик (navigator.vibrate 10ms) на commit — за настройкой.

## 15. Текстовые микро-правила в экранах

Каждый экран MVP имеет ≤ 1 панк-фразы в фокусе (не превращать в стену): см. примеры выше; генерация новых — по style-tone.txt «формула 99/100», шкала жестокости 70–85 на обычных экранах, 99 только на Debrief/поражениях. Запрещено высмеивать бедность/болезни/жертв — только рынок, китов, инфлюенсеров, регуляторов и жадность самого игрока.
